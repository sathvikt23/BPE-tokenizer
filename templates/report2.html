Pipeline Cleaning Strategies Overview

Total Strategies Identified: 9 Core Cleaning Stages

Session 3 outlines a complete 9-stage data curation hierarchy designed to transform dirty, raw web text into high-reasoning LLM pre-training tokens. Each stage targets a specific vector of noise, degradation, or security risk.

Stage 1 Language Filtering
1. Language Identification
Detects and tags the language of each incoming document. Filters out non-English text to prevent token vocabulary dilution and cross-lingual loss spikes during English LLM pre-training.
lingua-py Language.ENGLISH Min 30 chars
Stage 2 Deduplication
2. Exact & Near Deduplication
Identifies and removes exact document hashes as well as near-identical web boilerplate using 128-permutation MinHash LSH with a 0.90 Jaccard similarity threshold to prevent memorization.
Python hash() datasketch MinHashLSH Threshold = 0.90
Stage 3 Text Repair
3. Text Extraction & Normalization
Strips raw HTML tags, unescapes HTML entities, repairs corrupted Unicode text encodings, converts to NFKC standard form, strips control characters, and collapses extra whitespaces.
BeautifulSoup4 ftfy.fix_text unicodedata NFKC Regex Scrubbing
Stage 4 Rule-Based Filter
4. Heuristic Quality Filtering
Enforces statistical rules targeting web junk, SEO spam, and short fragments: word counts (20-5000), minimum alphabetic ratio (≥60%), max punctuation (≤30%), and boilerplate rejection.
Word Count Check Alpha Ratio ≥ 0.60 Boilerplate Matcher
Stage 5 ML Quality Scoring
5. ML-Based Quality Classification
Leverages FineWeb-Edu neural quality classifier to score text educational value. Filters out grammatically sound but low-information text with a score threshold ≥ 0.5.
FineWeb-Edu Classifier HuggingFace Pipeline Threshold ≥ 0.5
Stage 6 Domain Rules
6. Custom Task Filtering
Validates structural syntax and sentence density for downstream reasoning tasks: checks minimum sentence length (≥5 words), digit ratios (≤40%), uppercase ratios (≤60%), and vocabulary diversity.
TaskFilter Digit Ratio ≤ 0.40 Unique Word Ratio ≥ 0.30
Stage 7 Privacy Protection
7. PII Detection & Anonymization
Identifies and redacts Personally Identifiable Information (PII) such as email addresses and URLs using regular expressions to maintain context while guaranteeing data privacy.
Email Scrubbing URL Redaction Regex Redactor
Stage 8 Data Mixture
8. Domain Classification & Clustering
Categorizes cleaned documents into data pools (D1–D4 & AON) using zero-shot classification with BART-Large-MNLI across 9 categories (Books, Science, Code, Wiki, Web, etc.).
BART-Large-MNLI Zero-Shot Classifier D1–D4 Data Pools
Stage 9 Human QA
9. Human Quality Evaluation
Spot-checks random statistical samples post-pipeline to verify filter precision, assess false positive drop rates, and calibrate quality thresholds before pre-training.
Stratified Sampling Human Spot-check Precision QA

Dataset Selection & Technical Rationale
Why monology/pile-uncopyrighted and why cap at 100MB?

Picked Dataset: monology/pile-uncopyrighted

For this curation pipeline benchmark, we selected monology/pile-uncopyrighted. This dataset is an open-source, sanitized variant of EleutherAI's Pile, specifically filtered to remove copyrighted books (e.g. Books3) while retaining rich, heterogeneous text streams.

Key Subsets Represented: PubMed Central, ArXiv scientific preprints, Wikipedia, GitHub source code, HackerNews discussions, StackExchange, and OpenWebText.

Why Cap at 100 MB? (Storage & Execution Constraints)

  • Storage & RAM Constraints: Prevents disk overflow and out-of-memory errors on local CPU/GPU execution environments.
  • Streaming High Throughput: Utilizing HuggingFace streaming=True streams chunks on the fly without downloading giant 800GB tarballs.
  • Statistical Validity: A 100MB slice yields ~27,800 clean documents, providing high statistical confidence to measure deduplication collisions and domain mixture percentages.
  • Zero-Shot Inference Latency: BART-Large-MNLI and FineWeb-Edu CPU inference require bounded document batch sizes for interactive iteration.

from datasets import load_dataset
from cleaning.clean import cleaner 
from tqdm import tqdm
import os

# Stream English Pile dataset
ds = load_dataset(
    "monology/pile-uncopyrighted",
    split="train",
    streaming=True
)

TARGET_SIZE = 100 * 1024 * 1024     # 100 MB target size
current_size = 0
OUTPUT_DIR = "output"
os.makedirs(OUTPUT_DIR, exist_ok=True)

for sample in tqdm(ds):
    text = sample["text"]

    # Stage 1: Language Identification
    if not cleaner.is_english(text):
        continue

    # Stage 2: Exact & Near Deduplication
    if not cleaner.exact_duplicate(text): continue
    if not cleaner.near_duplicate(text):  continue

    # Stage 3: Normalization
    text = cleaner.normalize(text)

    # Stage 4: Heuristic Quality Filtering
    if not cleaner.heuristic_quality(text): continue

    # Stage 5: ML-Based Quality Classification
    if not cleaner.ml_quality(text): continue

    # Stage 6: Custom Task Filtering
    if not cleaner.custom_filter(text): continue

    # Stage 7: Remove PII
    text = cleaner.remove_pii(text)

    # Stage 8: Domain Classification
    domain = cleaner.classify_domain(text)
    filename = domain["domain"].replace(" ", "_").lower() + ".txt"

    size = len(text.encode("utf-8"))
    if current_size + size > TARGET_SIZE:
        break

    with open(os.path.join(OUTPUT_DIR, filename), "a", encoding="utf8") as f:
        f.write(text + "\n")
    current_size += size

from lingua import Language, LanguageDetectorBuilder
from datasketch import MinHash, MinHashLSH
import re, html, ftfy, unicodedata, string
from bs4 import BeautifulSoup

class cleaner: 
    def __init__(self):
        self.detector = LanguageDetectorBuilder.from_languages(Language.ENGLISH).build()
        self.seen_hashes = set()
        self.lsh = MinHashLSH(threshold=0.90, num_perm=128)
        self.doc_id = 0
        
        self.url_pattern = re.compile(r"https?://\S+|www\.\S+")
        self.email_pattern = re.compile(r"\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}\b")
        self.control_pattern = re.compile(r"[\x00-\x08\x0B\x0C\x0E-\x1F\x7F]")
        self.whitespace_pattern = re.compile(r"\s+")

    def is_english(self, text: str) -> bool:
        if text is None or len(text.strip()) < 30: return False
        return self.detector.detect_language_of(text.strip()) == Language.ENGLISH

    def exact_duplicate(self, text: str) -> bool:
        h = hash(text)
        if h in self.seen_hashes: return False
        self.seen_hashes.add(h)
        return True

    def near_duplicate(self, text: str) -> bool:
        m = MinHash(num_perm=128)
        for word in set(text.split()): m.update(word.encode("utf8"))
        result = self.lsh.query(m)
        if len(result) > 0: return False
        self.lsh.insert(str(self.doc_id), m)
        self.doc_id += 1
        return True

    def normalize(self, text: str) -> str:
        text = BeautifulSoup(text, "html.parser").get_text(" ")
        text = html.unescape(text)
        text = unicodedata.normalize("NFKC", ftfy.fix_text(text))
        text = self.control_pattern.sub("", text)
        text = self.whitespace_pattern.sub(" ", text).strip()
        return text

from transformers import pipeline

class QualityClassifier:
    def __init__(self, model_name="HuggingFaceFW/fineweb-edu-classifier", threshold=0.5):
        print("Loading Quality Classifier...")
        self.classifier = pipeline(
            task="text-classification",
            model=model_name,
            device=-1      # CPU Execution
        )
        self.threshold = threshold

    def score(self, text):
        if len(text) > 4000: text = text[:4000]   # Length Guard
        return self.classifier(text)[0]

    def is_high_quality(self, text):
        result = self.score(text)
        return result["score"] >= self.threshold

from transformers import pipeline

class DomainClassifier:
    def __init__(self):
        print("Loading Zero-Shot Domain Classifier...")
        self.classifier = pipeline(
            "zero-shot-classification",
            model="facebook/bart-large-mnli",
            device=-1
        )
        self.labels = [
            "Web Page", "News", "Research Paper",
            "Book", "Documentation", "Forum Discussion",
            "Code", "Mathematics", "Wikipedia"
        ]

    def classify(self, text):
        if len(text) > 3000: text = text[:3000]
        result = self.classifier(text, self.labels)
        return {"domain": result["labels"][0], "score": result["scores"][0]}

import re

class TaskFilter:
    def __init__(self):
        self.min_sentence_length = 5
        self.max_digit_ratio = 0.40
        self.max_uppercase_ratio = 0.60
        self.min_unique_word_ratio = 0.30

    def passes(self, text):
        sentences = [s for s in re.split(r"[.!?]", text) if len(s.split()) >= self.min_sentence_length]
        if len(sentences) < 1: return False
        
        digits = sum(c.isdigit() for c in text)
        if (digits / max(1, len(text))) > self.max_digit_ratio: return False

        letters = [c for c in text if c.isalpha()]
        if letters and (sum(c.isupper() for c in letters) / len(letters)) > self.max_uppercase_ratio: return False

        words = text.lower().split()
        if words and (len(set(words)) / len(words)) < self.min_unique_word_ratio: return False

        return True

Additional Curation Strategies & Architectural Concerns
Handling memory constraints, MinHash LSH scaling, and PII anonymization trade-offs

1. Memory & Latency Bottlenecks

Zero-shot classification with BART-Large-MNLI and FineWeb-Edu quality scoring are computationally expensive on CPU. Enforcing strict character truncation (text[:4000]) prevents sequence length explosion and quadratic attention overhead while maintaining high classification accuracy.

2. MinHash LSH Permutation Scaling

Choosing 128 permutations vs 64/256 and setting a 0.90 Jaccard threshold strikes an optimal balance. It reliably detects near-duplicate web templates without incorrectly dropping distinct technical documentations or code samples that share repetitive syntax.

3. PII Redaction vs Document Drop

Rather than discarding an entire 2,000-word research article due to a single email address in the author footnote, regex-based inline scrubbing (remove_pii) redacts sensitive tokens while retaining the surrounding scientific content.
